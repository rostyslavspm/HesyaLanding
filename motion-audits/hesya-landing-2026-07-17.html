Overall

Hesya has ambitious motion — hero displacement, a 400vh pinned deck, SVG tab underlines. The craft is real, but ambient layers compete and scroll-scrub uses per-frame gsap.set instead of interruptible transitions. Tighten the always-on motion; keep the scroll-story moments.

Findings with live demos

CriticalEmilJakub

Two competing breathe loops on glass surfaces

ambientBreath (24s) runs on every .glass-panel while feature-media-breathe (8s) runs on mobile feature cards. Both scale opacity — the anti-checklist definition of "pulsing UI." For a calm wellness brand, one subtle ambient layer is enough.

Location app/design-system.css:268, app/design-system.css:927

Fix

Pick one breathe (or none). If kept, single 30s+ loop at <1% scale change, and gate behind prefers-reduced-motion (partially done — verify both are disabled).

CriticalJakub

Pin deck uses gsap.set on every scroll frame

ScrollTrigger onUpdate calls gsap.set on all panels and screens each frame. Tab clicks snap via snapDeckToFeature, but mid-scroll reversals feel glued to scroll position rather than interruptible. Jakub's rule: meaningful state changes need transitions users can cut short.

Location hooks/useFeaturePinScroll.ts:246–264

Fix

Consider a single scrubbed timeline with labeled segments, or CSS transition on opacity/transform when tab/hash fires. Keep scrub for scroll, but decouple programmatic navigation from per-frame sets.

Uniform fade-up scroll reveals

Manifesto teaser and download section both use gsap.from with opacity: 0, y: 32 at start: "top 75%". Same choreography twice on one page reads as template motion, not intentional pacing.

Location components/sections/ManifestoTeaser/index.tsx, components/sections/DownloadSection/index.tsx

Fix

Vary entrance: manifesto could split copy/visual with 40ms stagger; download could scale from 0.98 with opacity only. Match the calmer brand tone.

ImportantEmil

btn-magnetic hover scale on CTAs

Primary CTAs scale on hover (.btn-magnetic:hover). Emil's anti-pattern: hover-scale on interactive targets. For marketing CTAs frequency is lower than utility apps, but it still fights the "calm" positioning — especially combined with glass breathe.

Location app/design-system.css:358

Fix

Replace scale with background/opacity shift over 150ms, or a 1px translateY lift. Keep focus ring as-is.

ImportantJakubEmil

Dual motion stacks (GSAP + Framer Motion)

GSAP owns scroll (pin, drift, reveals); Framer Motion owns header entrance and FAQ accordion. Both ship to the client. Reduced-motion is handled in both places but inconsistently (useMotionEnabled vs useReducedMotion).

Location components/Header.tsx, components/FaqAccordion.tsx, hooks/useFeaturePinScroll.ts

Fix

Consolidate on GSAP for scroll-driven work; migrate header/FAQ to CSS transitions or a single animation layer. Unify reduced-motion gate.
